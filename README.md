# AI 多端协作通信原型

项目提供本地 MCP 任务、消息、产物和会话控制接口。开发语言为 JavaScript ESM，使用 Node.js 24、官方 MCP SDK、Zod 和 SQLite WAL。

当前实现包括：

- 固定角色的 stdio 通信桥：派单、问答、读取确认、产物版本和审核记录。
- 产物实际内容传输、SHA256 核对及规范路径和真实路径访问限制。
- 本机 HTTP 只读探针：随机本地身份、现场挑战码及脱敏请求审计。
- 受限任务 HTTP 传输可由可信启动按原绑定恢复凭据，保留旧部署并独立审计；恢复连接不会重新领取或执行业务。
- 独立伙伴通道：固定 manager/workbuddy 身份，双向消息、显式读取确认及文本产物的版本与哈希。
- Claude/Cowork 文件交接：独立任务输入、固定输出读回、SHA256 快照与版本审核；同版本的最新有效审核决定状态。
- 会话控制：按平台和产品模式报告能力，保存平台原始会话编号，支持任务目录绑定、操作去重与结果读取；未核实模式明确关闭。
- 每任务独立的输入、工作和输出目录；创建时绑定，续接前核对原目录和真实路径。
- 默认关闭的 Claude Code 独立会话适配器；普通桌面、命令行和云端模式分别记录。
- 默认关闭的 CodeBuddy CLI 独立文本会话适配器；单能力或显式受限文件工具集、任务审计与平台原始编号分列，桌面上下文不作等价推定。
- manager 可通过现有 MCP 持久安排建聊或按原生编号续发，再显式唤醒一次受管执行；入队、本地执行器启动、平台进程启动与执行终态分别记录。未知、过期或重复请求不会自动重新投递。
- 任务文件工具实际读写 inputs/work/outputs 各自 files 子目录中的有界 UTF-8 文本，核对目录身份、普通文件、硬链接及写后哈希；模型只能读取输入，输出与工作文件不覆盖已有内容。
- 同一 CodeBuddy 适配器支持显式审查的独立官方包布局；包清单、版本、入口与运行文件必须通过 pin 前检，不猜测宿主 bundle、不自动迁移认证或旧配置。
- 后台执行计划、事件解析和用量归一化，默认保持模型执行关闭。
- 并发初始化、去重、恢复、版本失效和权限范围的本地测试。

开发代码位于 `bridge/src/`；开发脚本位于 `bridge/scripts/` 和 `scripts/`；测试位于 `tests/`。依赖版本在清单和锁文件中固定。

现有 MCP 工具连接不等于外部会话控制已通过。WorkBuddy、豆包和 Claude 的接口、鉴权、目录与运行状态分别核实，未核实能力返回明确原因，不以本地编号或测试数据代替平台回执。工作目录与文件访问权限分别验收，目录生效不代表整个平台进程被隔离。

Cowork 文件桥记录实际文件观察和审核，不自动创建或唤醒平台任务。平台执行来源、原始会话编号、运行时目录与文件权限另行验证；历史读回和审核重放会核对绑定、快照及当前输出，避免旧结果继续被视为当前有效。

本地测试不调用真实账号或模型，也不提升真实平台验证状态。受管执行、文件工具策略、独立文件执行器的 OS 范围和整个平台 OS 范围分别验收；无正式接口或身份条件时返回结构化阻塞。豆包正式外部会话契约未取得时继续关闭；新增执行能力不扩展 Claude。后台模型完整执行、视频生成和自动唤醒尚未完成端到端验收。旧一次执行入口的 stderr 停止分类有已知限制，不能仅凭日志等级判断业务失败或成功。

仓库仅保存经过审查的开发文件。个人使用方法、部署配置、真实运行证据、数据库、生成产物、密钥及认证数据保留在本地。
